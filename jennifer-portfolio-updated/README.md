## Maintain the site

The public homepage is `index.md`. This README is for the GitHub repository, not the public homepage.

- Edit `_config.yml` for the site identity, contact details, deployment path, and optional resume link.
- Edit `_data/samples.yml` for card titles, descriptions, ordering, audiences, skills, and featured status. Set `featured: true` on the three samples to highlight.
- Edit `index.md` for the introduction and About copy.
- Edit the existing sample Markdown files to update the writing itself. Keep their YAML front matter at the top.
- Edit `assets/css/portfolio.css` for colors, spacing, typography, and responsive layout.

Read `PORTFOLIO-UPDATE-NOTES.md` before publishing. It includes setup instructions, exact changes, known issues in the original samples, and verification limitations.
